01 / Project overview

Why study nature through texts?

The project treats literary and reference works as sources in which descriptions, names, and classifications of living organisms can be located and organised.

Abstract

This project explores the extraction and organisation of flora and fauna references from five literary and reference texts through a Retrieval-Augmented Generation (RAG)-oriented framework. The supplied dataset groups references into predefined flora categories—Trees, Plants, Flowers, Herbs and Crops—and fauna categories—Mammals, Birds, Reptiles, Fish and Insects. Each extracted record carries a name, category, common name, textual quotation, source location, status and remarks. The dataset contains 78 records: 19 flora and 59 fauna. Sixty-two are marked “Verified” and 16 “Ambiguous” in the project file. An interactive catalogue is provided to inspect the entries, compare sources and identify classification issues. The exercise demonstrates how structured extraction can support textual exploration while also showing why human review and taxonomic validation remain necessary.

Scope note: “Verified” and “Ambiguous” reproduce the status labels in the supplied file; they should not be read as independent scientific verification carried out by this webpage.

Introduction

Literary and reference texts often contain descriptions of animals, plants, landscapes and ecological settings. These references may appear as scientific names, common names, local names or broader descriptions. Finding them manually across multiple works can be time-consuming. A structured extraction approach can make such material easier to search, compare and analyse.

This project organises extracted references under flora and fauna and links each record to the text in which it appears. It brings together five sources, including Fishes of India, Jim Corbett’s works and a biodiversity reference text. Although the project title foregrounds Indian cultural elements, the supplied records also include globally distributed or non-native examples. The catalogue therefore preserves the source data and makes its geographic and taxonomic limits visible.

Objectives

  • Identify flora and fauna references appearing in the selected texts.
  • Organise extracted entities into consistent categories.
  • Retain textual evidence and source-location information for traceability.
  • Distinguish records marked verified from those marked ambiguous.
  • Examine patterns, gaps and classification problems in the extracted dataset.

Research questions

  1. What flora and fauna entities are represented across the five selected texts?
  2. Which categories and sources contribute the largest number of records?
  3. How effectively do the current category labels represent the extracted entities?
  4. What kinds of ambiguity emerge when biological references are organised automatically or semi-automatically?

01

Fauna dominates the extracted dataset

There are 59 fauna records compared with 19 flora records. “Fishes of India” contributes 16 fish records, while “Man-Eaters of Kumaon” contributes a varied group of mammals, birds and reptiles.

02

The sources have distinct subject emphases

“Fishes of India” contributes only fish in the current data. “Man-Eaters of Kumaon” includes forest plants and wildlife, while “Fundamentals of Biodiversity” mainly contains broad ecosystem and biodiversity references.

03

Some entries are not individual species

Examples include “Forests”, “Grasslands” and “Wetlands”, which are habitat or ecosystem terms, and “Indian fauna”, which is a broad biogeographical phrase.

04

Category boundaries need attention

“Frog” appears under Reptiles but is marked Ambiguous in the source file with a note that it is an amphibian. Several microscopic organisms are placed under Insects or Mammals with ambiguous status.

05

Evidence fields improve traceability

Quotations, source locations and remarks make it possible to revisit an entry instead of relying only on a generated label. Some quotations are simply the extracted name, so evidence depth is not uniform.

06 / Critical reflection

Limitations & data-quality considerations

The current file is a useful structured starting point, but it should not be treated as a complete or taxonomically audited biodiversity catalogue.

Limitations

  • The supplied file includes extracted outputs but not the actual RAG pipeline or its technical configuration.
  • The five sources are not accompanied by full bibliographic details, editions or page numbers.
  • There is no documented sampling strategy, recall/precision evaluation or comparison with a gold-standard dataset.
  • Some records use broad groups or common names rather than precise species-level identifiers.
  • Some entries are non-Indian or globally distributed, so the dataset does not exclusively represent Indian flora and fauna.
  • Empty categories mean no entry is present in this dataset; they do not prove that the source text contains no such references.

Ambiguity examples

  • Frog: listed in Reptiles; the remarks correctly flag it as an amphibian.
  • Demodex folliculorum: listed under Mammals, but described as a microscopic parasite and marked Ambiguous.
  • Achlya prolifera: listed under Insects, though the remarks identify it as an oomycete/biological entity.
  • Anguillula entries: identified as roundworms and marked Ambiguous under Insects.
  • Forests, Grasslands and Wetlands: habitat/ecosystem concepts placed in flora categories.

Interpretive caution: The webpage preserves spellings and classifications from the source dataset—including unusual or possibly outdated taxonomic forms—so they can be checked later. It does not silently normalise or correct names.

08 / Conclusion

What the current dataset tells us

The current extraction organises 78 flora and fauna references across five texts into a searchable structure. It shows how text-based extraction can make nature-related references easier to compare across literary and reference sources. At the same time, the 16 ambiguous records and several category mismatches demonstrate that extraction is not the same as validation. A reliable RAG-based research resource should preserve textual evidence, provide precise source citations, distinguish species from habitats and broad concepts, and include expert review of biological classifications. The present project is therefore best understood as an exploratory catalogue and a foundation for a more reproducible extraction and validation workflow.
